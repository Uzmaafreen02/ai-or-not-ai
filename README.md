# AI OR NOT AI? — Offline Classroom Game

## How to play
1. Keep `index.html` and all `q1`–`q15` image files in the same folder.
2. Open `index.html` in a web browser (Chrome recommended).
3. Click **START**, follow the instructions, and play.

No Google Sheets, Google Apps Script, login, student details, or internet connection is required. The game shows each player's score on the result screen. Scores are not uploaded or stored centrally.
